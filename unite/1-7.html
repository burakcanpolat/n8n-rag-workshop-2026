Adımlar

A n8n Agents Knowledge (5 dk)

  1. n8n Agents'ta önceden kurulan Imbat Bilgi agent'ı: Instructions alanında P13, Knowledge'da kitin belgeler/ klasöründeki 6 md dosyası.
  2. P14 gönderilir.
  3. Oturumdaki araç çağrıları okunur: dosya adlarını tarama, rg araması, satır okuma.

B Claude Code grep (4 dk)

  1. Claude Code, kit klasöründe açık bir oturum; P15.
  2. Transcript'te Grep ve Read çağrıları ve bulunan dosya adı.

C MCP köprüsü (5 dk)

  1. 05-kb-mcp'nin yapısı: MCP Server Trigger ve ona bağlı imbat_bilgi_bankasi aracı.
  2. Terminalde önceden çalıştırılmış P16 ve claude mcp list çıktısı. Komuttaki adres (https://n8n.burakcanpolat.dev/mcp/imbat-kb) eğitmenin instance'ı; kendi kurulumunda ekrandaki Production URL'i esas al, <TOKEN> yerine kendi token'ın gelir; token ekranda gösterilmez.
  3. Claude Code'da P17: imbat_bilgi_bankasi çağrısı, dönen 4 parça ve kaynak etiketleri.

D Executions (2 dk)

  1. n8n Executions'ta 05-kb-mcp çalıştırması: alt akışın girdisi (soru) ve çıktısı.
terminal: bağlantıyı kontrol etKopyalandı
claude mcp list

Ne görürsün Üç yoldan aynı sonuç: yüzde 50 iade, 03-iptal-ve-iade.md. P17: 7 iş günü, kesinti yok; soru belgeyle aynı kelimeleri paylaşmasa da anlam araması buldu.

Neden Üç yeni kapı, aynı arşiv. n8n Agents'ta Knowledge'a dosya koyarsın; agent dosya adlarını tarar, ripgrep ile kelime arar ve gereken satırları okur, embedding yoktur. Claude Code aynı klasörde grep ile arar; Anthropic'e göre CLAUDE.md baştan yüklenir, glob ve grep ihtiyaç anında çalışır (2025-09-29). Köprüde Claude Code, n8n bilgi bankamızı MCP ile bir araç olarak çağırır ve embedding n8n'de çalışır; bu, instance'ı yöneten MCP sunucusundan farklı bir köprüdür. Kelime araması kodları ve tam adları iyi bulur, anlam araması kelimeler örtüşmediğinde kazanır: Türkçe ekler ve karaktersiz yazım tam bu durumdur.

Bozulursa (evde) n8n Agents önizleme (Preview) aşamasında: kendi sunucunda modülün açılması ve Knowledge için Daytona gerekir, queue mode desteklenmez (R4). MCP aracı boş dönüyorsa önce 01'i çalıştır. Bağlantı kurulmuyorsa workflow'un yayında olduğunu ve Production URL'yi kullandığını kontrol et: test URL yalnız n8n dinlerken çalışır. Token'ı kite koyma, ekranda gösterme.

Sadece izliyorsan Her yolun sonundaki dosya adına bak: aynı belge, üç farklı arama.
